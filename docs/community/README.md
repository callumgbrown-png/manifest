# Community kit

Ready-to-use documents for the community ideas that live outside the game (posts, pages, contests, videos).
In-game parts are feature modules in `server/src/features/community/` (see `docs/features/reports/community.md`).
Links that the game shows go in `config/links.json`; codes for anything sold or given away outside the game are made
with `node tools/community/make-codes.mjs` and redeemed in the game's Community panel.

Placeholders look like `[LINK]`, `[DATE]` or `[N]`. Fill them in before posting.

## Ground rules for everything here
- **No real money in the game.** Purchases happen on itch.io, Bandcamp or Ko-fi. Buyers get an unlock code for a cosmetic pack. Cosmetics never change stats.
- **No personal data.** Prizes go out as unlock codes by Discord DM or e-mail from the shop, never stored in the game. Contest entries need the entrant's consent to be shown.
- **Fair prizes.** Prizes are cosmetics, dedication tokens or tester points, never credits or anything that changes how the game plays.
